# インスタ運用ツール：おおまかなやり方

AI 活用術アカウント向けの「リサーチ → 台本作成」自動化ツールの計画。

## 基本の考え方

**AI に全部任せない。AI と自分で役割を分ける。**

- AI が得意：新しい情報を集める、整理する、文章の形にする
- 自分にしかできない：実際に使った感想・体験・意見

フォロワーが保存したくなるのは「自分の体験」の部分なので、そこは自分で書く。

## 使う道具

- **Google スプレッドシート**：すべての作業場所
- **GAS（Google Apps Script）**：自動で動かす仕組み
- **AI（Claude や ChatGPT）**：調べる・書く担当

## 流れ（5ステップ）

| # | ステップ | 担当 | やること |
|---|---|---|---|
| 1 | ネタ集め | AI（自動） | 毎朝、AI の新機能やニュースを調べてシートに一覧で入れる |
| 2 | 選ぶ | **自分** | 気になったネタに ✅ を付け、実際に試した感想をひとことメモ |
| 3 | 台本作成 | AI（自動） | ✅ が付いたら、ネタとメモから台本を書く |
| 4 | 仕上げ | **自分** | 自分の言葉に直して完成 |
| 5 | 学習 | 自動 | 直した台本を保存し、次回からのお手本にする |

ステップ2の ✅ が「承認ボタン」。押すと次のステップに自動で進む。

## 台本の形

1. **冒頭3秒の引き**（例：「これ知らないと損してます」）
2. **本編**（使い方を3ステップで）
3. **👉 自分の感想**（自分のメモを使う。AI に作り話をさせない）
4. **締め**（例：「保存して後で試してね」）

## スプレッドシートの構成

- シート1「ネタ一覧」：AI が集めたネタ ／ ✅ 欄 ／ 自分のメモ欄
- シート2「台本」：AI の下書き ／ 自分の修正版
- シート3「お手本」：過去の修正版（自動でたまる）

## 使うほど良くなる理由

自分が直した台本がたまるほど、AI が「自分らしい書き方」をまねできるようになる。

## 追加：競合分析（伸びてる／伸びていないを見分ける）

### やりたいこと
1. 競合アカウントの外から見える情報を集める
2. 投稿の台本（中身）を見る
3. 伸びてる投稿と伸びていない投稿を分ける
4. 違いを「抽象」と「具体」の両方で言えるようにする

### 1. 外から見える情報（Instagram の公式 API で取れるもの）
- フォロワー数、投稿数
- 各投稿のキャプション、いいね数、コメント数、投稿日時、種類（リール／カルーセル）
- 条件：自分のアカウントがビジネス／クリエイターアカウントであること。相手もビジネス／クリエイターアカウントであること
- 取れないもの：他人の再生数・保存数・リーチ、いいね数を非表示にしている投稿のいいね数
- スクレイピング（画面から無理やり抜き出すこと）は規約違反になるので使わない

### 2. 台本
- キャプションは自動で取れる
- リールで話している内容やカルーセル画像の中の文字は自動で取れない。自分で書き起こすか、AI に動画・画像を読ませて文字にする

### 3. 伸びてる／伸びていないの判定
- 判定の基準：（いいね＋コメント）÷ フォロワー数
- 同じアカウントの平均と比べる（例：平均の2倍以上 → 伸びてる、平均の半分以下 → 伸びていない）
- アカウントごとの平均と比べるので、規模の違う競合どうしでも比べられる

### 4. 抽象と具体で分析
各投稿について、AI が2段階で書き出す。

| | 具体（何を言ったか） | 抽象（なぜ効くのか＝型） |
|---|---|---|
| 冒頭 | 「ChatGPT のこの設定、オフにしてないと危険です」 | 損をしたくない気持ちに訴える |
| 本編 | 設定画面を3ステップで説明 | すぐ真似できる手順 |
| 締め | 「保存して今すぐやってね」 | 保存する理由をはっきり言う |

伸びてる投稿の「型」と伸びていない投稿の「型」を並べて、違いを見つける。

### 自分の台本への使い方
**伸びてる「型」（抽象）＋ 自分の体験（具体）＝ 自分の台本**

- 他人の投稿をそのまま真似せずに、型だけ借りる
- 中身は自分で試した体験で埋める

### シートを追加
- シート4「競合アカウント」：調べたいアカウントの ID を入れる
- シート5「競合投稿」：自動で集めた投稿、判定結果（伸びてる／普通／伸びていない）、具体、抽象
- シート6「伸びる型」：伸びてる投稿に多い型のまとめ（台本作成のときに AI が参考にする）
